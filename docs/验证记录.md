## 交互逻辑检查

`tools/check_interactions.cjs` 运行实际交付的 `config.js` 和 `app.js`，通过最小浏览器 API 模拟检查以下 8 组行为：

1. 封面启封、焦点控制、Tab 焦点限制、音乐播放／暂停／继续、重播不重复创建花瓣。
2. 按中国时间 17:08 计算倒计时、逐秒更新、后台暂停后前台校准、到时归零。
3. 剪贴板成功、剪贴板权限被拒时回退、无剪贴板 API 时的传统复制。
4. 播放权限被浏览器拒绝时，正文仍可使用并显示手动播放提示。
5. 系统减少动态效果／没有 IntersectionObserver 时不隐藏正文。
6. 换域名、子目录和分享参数下的运行时相对地址解析。
7. 音频加载错误提示。
8. 无需安装软件的分享配置工具：修改 5 个静态标签、保留正文、拒绝无效输入。

`tools/check_static.py` 检查资源路径、地图参数、原托管依赖、日历时间、分享配置工具和交付文件哈希。

这些是**代码逻辑和文件检查**，浏览器 API 使用测试替身；不等同于真实浏览器渲染、音频输出或手机 App 跳转验证。
